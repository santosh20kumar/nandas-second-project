# Nanda's Creative — Bakery Ordering Website

Customized for Nanda's Creative, Hyderabad.

## Included
- Bakery menu and category filtering
- Shopping cart
- Delivery checkout
- Cash on Delivery / UPI on Delivery
- Order storage and order tracking
- Staff dashboard
- WhatsApp order notification link
- Nanda's Creative logo

## Run locally
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## Admin
Open `http://localhost:3000/admin.html`

Default admin password: `nandas2026`
Change it before putting the site online.

## Production note
This is a starter ordering system. Before public launch, use a proper database/authentication setup and connect a verified online payment gateway if you want customers to pay online.
